# Elephant-Goldfish Model (EGM) Rules for Continue

This workspace uses the Elephant-Goldfish Model for Spec-Driven Development.

## Workflows:
- `/egm-brainstorm`: Zero-doc ideation with multi-lens shootdown swarm.
- `/egm-draft`: Section-by-section markdown design specification compiler.
- `/egm-review`: Strict 4-stage verification (Zoom Out -> Comprehension -> Critic -> Readiness).
- `/egm-review-loop`: Concurrent review subagent dispatch engine.
- `/egm-resolve`: Interactive triage and patch verification.
- `/egm-drift-report`: Specification vs code drift scanner (read-only).
- `/egm-bootstrap`: Recursive blueprint and package contract generator.

All findings adhere to the 11-field Standard Review-Finding Contract in `resources/finding_contract.md`.
